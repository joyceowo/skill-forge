# Code Atlas viewer

## Purpose / mode
Operate + Read: SA、SD、PG 從國家逐層進入城市、鄉鎮，將功能說明與程式位置對照。
這是既定三層圓形包覆圖的工具表面，依 PLAN.md 與 schema.md 實作；不變更根 DESIGN.md。

## Confirmed content and constraints
繁體中文，離線靜態 HTML、本地 D3、無安裝、file://，按國家載入。真實文件驅動內容，無行銷數字。
搜尋、麵包屑、覆蓋率、未開發地區、鎮民、程式行號。圖形與清單提供同等鍵盤入口。

## Direction / first viewport
工程地圖工作台。紙白畫布、深海藍文字、青綠國家輪廓，未開發地區採赭色。
第一屏為精簡工具列、主圖與右方文件面板；工具列下方保留當前位置，不堆疊儀表卡片。
操作系統字型以確保繁中離線閱讀；代碼位置使用等寬字型。這是工具介面而非展示標題。

## Signature interaction
點進國家後只載入該國文件，圓形視野連續縮放到城市、鄉鎮；麵包屑可回退。
層級清單提供不依賴圖形的相同操作。縮放遵守 prefers-reduced-motion。

## States / quality bar
空圖、空國家、搜尋無結果、載入失敗與重試、長名稱、連點、重新整理均保留明確路徑。
桌面雙欄、窄螢幕圖形在前文件在後；文字和控制不橫向溢出。

## Verification / boundaries
Python 測試覆蓋 build 分塊、人工修正、來源保護、行號及 3,000 鄉鎮。
主代理負責 desktop/mobile 瀏覽器互動與獨立審查；本檔僅記錄此表面，不擴增產品規格。

## globe.html（分層架構地圖「深夜軌道」，2026-10-03 改版）
獨立的第二個表面，舊圓形包覆圖不受影響；共用 data/、vendor/ 與 file:// 限制。品質目標：Awwwards／FWA 等級。
目的：最外層看系統大方向，逐層降落看細項。軌道是正射投影星球（voronoi 領土＋航線），地表是玻璃色塊；一國一個寶石色。
方向：深太空底、大氣光暈、系統字型（數字與讀數用 Bahnschrift／DIN），右側玻璃面板，標題疊在舞台左上。
簽名互動：星球轉向、放大、攤平後降落；地表間被點色塊放大成舞台；高度計指針、高度與經緯度讀數、懸停卡、小地球。
狀態：開場由遠拉近、空圖、空國家、載入失敗重試、超過 48 項改卡片格、鎮民選取、減少動態直接到位、窄螢幕圖在上文件在下。
